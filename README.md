# Library (کتابا)

A Persian-language book library website built with React.

## Features
- Browse books and open a book to see its details
- View information about the author and explore the author's other books, with a short description of each
- Add books to a personal "My Library" page and view them there
- Read articles in the blog section
- About page with information about the site

## Tech stack
React 19, Vite, React Router, React Icons, json-server (mock API for development), persian-date, ESLint

## Live demo
https://librarybookss.netlify.app/

## Run locally
npm install
npm run dev
